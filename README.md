# MediTrack — Medicine Reminder & Adherence Tracker

MediTrack is a full-stack web application designed for elderly/chronic patients and their caregivers to manage medications, set scheduled reminders, and track adherence history.

## Tech Stack
- **Frontend**: React.js (Vite), Axios, Recharts, Plain CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **Auth**: JWT & bcrypt
- **Scheduled Jobs**: node-cron
- **Email Notifications**: Nodemailer

## Project Structure
```text
meditrack/
├── client/          # Vite + React frontend application
└── server/          # Express + Node.js backend API server
```

## Setup Instructions

### 1. Server Setup
```bash
cd server
npm install
npm run dev
```

### 2. Client Setup
```bash
cd client
npm install
npm run dev
```
